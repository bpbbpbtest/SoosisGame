# 🃏 SoosisGame — ربات تلگرام + مینی‌اپ بازی حکم

ربات تلگرام برای بازی‌های گروهی با مینی‌اپ؛ اولین بازی: **حکم چهارنفره** با قوانین کامل
(یارکشی با اولین آس، کوپ، تعیین خال حکم، بازی ۷ دستی، کت ۳/۲ امتیازی، بام).

همه‌چیز روی **GitHub Actions** اجرا می‌شود:

- `run-bot.yml` — هر ۵ دقیقه (یا دستی) ربات + سرور بازی را روی runner گیت‌هاب بالا می‌آورد،
  با یک تونل رایگان Cloudflare عمومی می‌شود، مینی‌اپ را روی **GitHub Pages** دیپلوی می‌کند و
  تا ~۳۵۰ دقیقه آنلاین می‌ماند. (محدودیت ۶ ساعتهٔ جاب‌های گیت‌هاب با این چرخهٔ خودکار دور زده می‌شود.)
- `ci.yml` — روی هر push: typecheck + تست‌های موتور بازی + build مینی‌اپ.

## ساختار

```
shared/   موتور بازی حکم (ماشین حالت، قوانین، امتیازدهی) + پروتکل WS + تست‌ها
server/   سرور HTTP+WS (بازی‌ها در حافظه) + ربات تلگرام (grammY، long-polling)
web/      مینی‌اپ (Vite + React + TS)
.github/workflows/  ci.yml و run-bot.yml
```

## راه‌اندازی (یک بار)

1. **ساخت مخزن و push**
   ```bash
   git init
   git add .
   git commit -m "hokm telegram bot + mini app"
   git remote add origin https://github.com/<USER>/<REPO>.git
   git push -u origin main
   ```

2. **توکن ربات** — از [@BotFather](https://t.me/BotFather) بگیرید و در مخزن ذخیره کنید:
   Settings → Secrets and variables → Actions → **New repository secret**
   | نام | لازم؟ | توضیح |
   |---|---|---|
   | `BOT_TOKEN` | ✅ | توکن ربات از BotFather |
   | `TG_OWNER_ID` | اختیاری | شناسه عددی شما؛ پیام «ربات آنلاین/آفلاین شد» برایتان می‌رود |
   | `WEBAPP_URL` | اختیاری | فقط اگر دامنهٔ سفارشی دارید؛ پیش‌فرض `https://<user>.github.io/<repo>/` |

3. **فعال‌سازی Pages** — Settings → Pages → Source: **GitHub Actions**

4. **تنظیم دامنهٔ مینی‌اپ در BotFather** —
   @BotFather → `/mybots` → ربات → Bot Settings → Mini Apps → Configure Mini App →
   دامنه را `<username>.github.io` بگذارید.

5. **اولین اجرا** — تب Actions → ورک‌فلوی **Run Bot** → **Run workflow**.
   بعد از سبز شدن، ربات در گروه دستور `/newgame` را جواب می‌دهد.

## استفاده در گروه

```
/newgame   → پیام با دکمه «🎲 ورود به بازی» (لینک مینی‌اپ با کد بازی)
/games     → فهرست بازی‌های در انتظار
/help      → راهنما
```

۴ نفر دکمه را می‌زنند → لابی → «شروع بازی» → کل جریان (کوپ، حکم، بازی، کت/بام) داخل مینی‌اپ.
نتیجهٔ نهایی بعد از پایان مسابقه در همان گروه پست می‌شود.

## نکات مهم

- **بازی‌ها در حافظهٔ runner نگهداری می‌شوند.** با پایان هر چرخهٔ ~۶ ساعته (یا ریستارت)،
  بازی‌های نیمه‌کاره از بین می‌روند و با اجرای بعدی ربات دوباره بالا می‌آید.
  (برای پایداری دائمی، بعداً می‌توان سرور را به VPS منتقل کرد — کد بدون تغییر کار می‌کند.)
- **اولین آس = حاکم؛ یار = نشست روبرو؛** تیم‌ها ثابت (نشست‌های ۱ و ۳ در برابر ۲ و ۴).
- امتیاز هر دور: برد معمولی ۱؛ **کت** (صفر کردن حریف) ۳ برای تیم مقابلِ حاکم و ۲ برای خودِ حاکم؛
  **بام** (۱۳ دست کامل) = برد فوری مسابقه. مسابقه تا **۷ امتیاز** (قابل تغییر با `MATCH_TARGET`).
- هر نوبت ۶۰ ثانیه وقت دارد؛ در صورت عدم اقدام، ورق/تصمیم خودکار زده می‌شود تا بازی قفل نکند.
- اگر `BOT_TOKEN` ست نشده باشد سرور فقط با `ALLOW_DEV=1` (توسعهٔ محلی) کلاینت می‌پذیرد.

## توسعهٔ محلی (اختیاری)

```bash
npm install
cp .env.example .env      # ALLOW_DEV=1 بگذارید
npm run dev:server        # سرور + ربات روی :8787
npm run dev:web           # مینی‌اپ روی :5173
npm run test              # تست موتور بازی
npm run lint              # typecheck همه‌جا
```

در حالت لوکال، صفحهٔ ورود دکمهٔ «ساخت بازی جدید (لوکال)» دارد و بازی‌ها از `POST /dev/games`
ساخته می‌شوند؛ ربط ربات (تلگرام) فقط با `BOT_TOKEN` واقعی کار می‌کند.
